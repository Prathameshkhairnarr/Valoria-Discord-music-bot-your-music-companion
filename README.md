## Meet Valoria

Music belongs to the room. Valoria brings song search, a shared queue and familiar playback controls into your Discord voice channel, with a pink visual identity and a choice of player appearances.

Discover regional and international songs, save the tracks you want to hear again, and let related-song autoplay continue your session. Available catalogs include Hindi, English, Marathi, Gujarati, Bengali and other languages; results depend on the selected source and its availability.

This is Valoria's **official public information and policies repository**. It contains brand assets, support information and public policies. The bot's source code, credentials, configuration and user databases are private.

## Built for the listening session

| Feature                       | What you can do                                                                   |
| :---------------------------- | :-------------------------------------------------------------------------------- |
| **Song discovery**            | Search by song name, select a result or use a supported song link.                |
| **Shared queue**              | See upcoming songs, reorder tracks, shuffle, remove or clear entries.             |
| **Player controls**           | Pause, resume, skip, stop, seek and change repeat mode.                           |
| **Related-song autoplay**     | Continue with recommendations informed by track metadata and musical preferences. |
| **Personal playlists**        | Create, edit, save and play playlists; share them when you choose.                |
| **Listener profiles**         | View your profile and approximate musical mood preferences.                       |
| **Server configuration**      | Configure DJ access, command prefixes, language and player appearance.            |
| **Server premium appearance** | Activate the music-card player appearance using a valid redeem code.              |

Autoplay is a lightweight metadata-based recommendation system. It can make mistakes and does not analyze your mental health or guarantee a particular mood, language match or uninterrupted playback.

## Start listening

In a server where Valoria is already installed:

1. Join a voice channel.
2. Run `/play` and enter a song name or supported song link.
3. Use the player buttons to control the session.
4. Open `/help` to browse the available commands.

**Try a search:** `Kesariya Arijit Singh` · `ABBA Gimme Gimme Gimme` · your favorite regional song.

Valoria focuses on songs. Spoken-content filtering uses metadata and can occasionally misclassify a result. Supported official music videos can supply audio for a song.

## Music catalogs & playback

| Selection                | How the current integration works                                                                                         |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| **YouTube**              | Song search and playback through the configured YouTube source.                                                           |
| **SoundCloud**           | Search and playback through the configured SoundCloud source.                                                             |
| **Spotify**              | Catalog metadata identifies the song; playback uses a YouTube audio match. Host API configuration is required for search. |
| **Apple Music / iTunes** | Catalog metadata identifies the song; playback uses a YouTube audio match.                                                |

Provider selection does not guarantee catalog availability, an exact recording match or a specific startup time. Valoria is independently operated and is not endorsed by these services or Discord. Provider names belong to their respective owners.

## A player for your server

**Standard appearance** keeps the session compact with a native Discord player and interactive controls.

**Server premium appearance** adds the custom music-card design for the server's shared player. Premium access is per server and can be activated through `/redeem` with a valid code. The Buy Now control is currently a placeholder; this repository does not offer a working checkout.

## Privacy & your choices

Valoria stores the information needed for features such as server settings, saved playlists, profiles and musical preferences. It does not record voice-channel conversations. Full details, retention information and deletion limitations are in the [Privacy Policy](PRIVACY.md).

- Use `/privacy` to find privacy information in Discord.
- Use `/deletedata` for the supported data-deletion options.
- Contact the operator for assistance or records outside those command options.
- Share playlists deliberately; sharing makes the relevant playlist information available to other users.

Read the [Terms of Service](TERMS.md) before using Valoria. This repository does not certify Discord verification, provider compliance or hosting security controls.
