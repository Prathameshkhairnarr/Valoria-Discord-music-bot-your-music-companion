# Security Policy

Report suspected vulnerabilities privately to **devsvicky0@gmail.com**, subject **Valoria security report**.

Describe the affected feature, steps needed to reproduce the issue, impact and a redacted example. Never include a live Discord token, hosting password, private database, unused premium code or unrelated user data. Do not test against other users or deliberately disrupt public services.

The operator will review the report and coordinate appropriate remediation and required notifications. No bounty or guaranteed response time is promised. Please avoid publishing exploit details or personal data while a report is being assessed.
