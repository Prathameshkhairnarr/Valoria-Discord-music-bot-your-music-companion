# Valoria Support

Contact **Vicky Khairnar** at **devsvicky0@gmail.com** for technical problems, abuse reports, copyright concerns, accessibility feedback and data requests.

For playback problems, include the command, song/public link, approximate time and a short description. Include a server/user ID only when needed. Remove tokens, passwords, private invite links, signed stream URLs and personal information from screenshots/logs.

You can use `/deletedata scope:user` to clear your saved playlists, bio, granted no-prefix access and personal preference data. A server manager can use `/deletedata scope:guild` to reset server settings and clear its taste/recent-history data. Premium entitlements are handled separately; contact the operator for entitlement-record deletion. Previously sent Discord messages and hosting backups are subject to separate controls. See the [Privacy Policy](PRIVACY.md).

Do not post sensitive reports or credentials in public GitHub issues. No support-server invite or response-time guarantee is currently published here.
